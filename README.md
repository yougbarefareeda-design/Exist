# Godot_Platform

Et lite 2D-plattformspill i Godot 4: en ridder, slimer, mynter og bevegelige plattformer.

Følger denne tutorialen: https://www.youtube.com/watch?v=LOhfqjmasi0

## Kom i gang

1. Trykk **Use this template** → **Create a new repository**.
2. I ditt nye repo: trykk **Code** → **Open with GitHub Desktop** → **Clone**.
3. Åpne Godot → **Create** → velg mappen du klonet → **Create & Edit**.
